对应你观察到的 LG700 现象：打开官方软件后，显示切回官方画面。此前写入的自定义动画仍保存在屏幕中。

!

建议完全退出官方软件，包括托盘进程，并关闭其开机自启动。
这样可避免进入 Windows 后，官方实时传屏重新接管当前显示。

为什么官方能很快切换画面？

官方只需把新素材的首帧送到屏幕，后续帧继续发送。本工具要完成整段素材的备份、写入、提交和完整读回，完成条件与数据量都不同。

“永久保存”与“始终显示”有什么区别？

永久保存指断电后素材仍保留。当前画面仍可能被官方传屏接管；屏幕完全断电时也无法显示。有供电并处于离线播放状态时，固件可独立播放。

流程图展示常规新素材写入。若完整核验发现目标内容已经相同，工具可跳过重复擦写。出现错误时停止后续流程；流程图中的向下箭头表示前一步成功后的路径。

当前工具 v1.2.2 在设备会话期间临时暂停官方主进程，结束或异常后恢复。它没有后台持续抢占显示的功能。离线循环模式也没有将屏幕锁定为独占状态。

“官方驱动”在这里主要指官方控制软件；底层 USB 通信使用 Windows 自带的 HID 驱动。日常“应用图片／视频”的实时通道中，目前未发现将整段素材快速提交到永久动画区的步骤。

# v1.2.7 实机验证记录

日期：2026-10-29。

## LG600

用户反馈修复版 v1.2.7 已在 LG600 实测通过。此前回传的 REV 0075 原始动画包含 480 帧，完整动画解析、首帧读取、原始字节备份和恢复校验均已通过离线验证。

实机通过结论来自用户反馈；未单独记录该次断电播放的验证范围。原始素材、诊断包及个人图片不随公开源码发布。LX800 仍待实机验证。

## LG700 REV 0075

本机曾在写前备份阶段出现读取续包残留，后续元数据查询或版本查询超时。故障时官方软件已完全退出。独立只读探测在等待版本命令 `0x87` 时收到旧读取命令 `0x0D` 的第 18 个续包 `0x0000120D`；重新打开 HID 并清空电脑端队列未恢复通信。

用户切断屏幕供电后重新上电，沿用产品原参数完成以下验证：

| 已有备份对比 | 与此前 REV 0067、REV 0075 有效备份一致 |
| 待机图读取 | 完整读取并通过格式校验 |

| 待机图写入及完整读回 | 50,613 字节，逐字节一致 |

本轮写入后的断电播放未另行验证。模式命令没有 ACK 或模式字节读取接口，后续版本查询正常不能当作模式字节读回。

## 结论范围

上述结果支持现有 V75 命令号、素材布局和本轮备份/写入流程正常；不能认定之前的故障由升级改变命令号导致。旧 REV 0067 的通信记录也出现过同类旧续包问题。

最初如何触发通信错位仍未定位。本次断电恢复后成功读取和写入，不表示该触发条件已被永久修复；v1.2.7 的 LG600 修复也未修改命令收发实现。此前的素材、原始备份及严格校验均保留。

# 官方传屏与硬件动画

v1.2.0 已删除“停止官方传屏”选项，以及自动结束、监控和重启官方软件的实现。

官方软件运行时会持续发送实时画面，可能覆盖硬件已经保存的自定义动画。写入成功与屏幕当前显示哪一路内容是不同的状态；需要查看离线素材时，请手动完全退出官方软件（包括托盘），并按需关闭其开机自启。

设备会话仍使用 `vendor_pause.py` 临时暂停官方主进程，避免 USB 操作期间出现并发传屏。会话结束或发生异常后恢复；暂停失败会阻止随后的设备操作。程序不会强制退出官方软件或在后台监测它。

本工具未增加或修改开机自启设置。提醒页只负责展示说明；首次确认记录保存在 `%LOCALAPPDATA%\TCOMAS-LG700-Tool\ui-preferences.json`，与屏幕素材和备份分开。

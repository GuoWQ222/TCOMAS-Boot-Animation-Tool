# v1.2.9 备份与离线播放验证

日期：2026-10-31。本机验证对象：LG700 REV 0075。

## 更新后的流程

- 自动写入、修复离线播放时，先查找本设备备份目录下的完整缓存。必须有设备身份键，型号、固件、身份一致，两个文件均通过 SHA-256 和素材格式验证，才可用于提前暂停播放。
- 有有效缓存时，先发送一次模式 0，再取得本次新的完整备份。新备份是实际擦写的必要条件，旧缓存不会替代它，不重复发送模式 0。
- 备份失败且开始前动画非空，恢复模式 1 仅尝试一次；模式发送结果未知时停止。空动画不启动不存在的循环。
- 已进入素材擦写后，失败仍停止，不自动重放擦除、数据、提交或模式命令，不启动可能尚未提交的动画。
- 恢复原动画时，先用已核验的恢复备份暂停播放，再备份当前素材。
- 没有有效缓存时，使用原先的完整备份流程。识别、硬件首帧和手动备份保持只读。

## 验证结果

114 项离线测试通过，包括空槽首次写入、缓存身份/版本/哈希检查、暂停与备份和写入顺序、备份失败后单次恢复、未知发送结果时停止、擦写不重发，以及保留原始备份失败时恢复循环。

维护模式下连续两轮读取，每轮取得完整动画 7,163,382 字节和待机图 29,865 字节，均逐字节匹配原备份，元数据不变。两轮合计约 233.4 秒。

另外运行实际 `backup_before_update` 路径，自动选择已核验缓存、提前暂停并生成新的完整备份，取得相同字节，耗时约 119.6 秒。结束后只发送一次模式 1，后续版本查询正常。

上述实测没有发送素材擦除、数据写入或提交命令；没有重新进行 LG600/LX800 写入或断电播放验证。模式没有读取接口，通信检查不等于观察到实体播放。USB 断连、错包或超时继续按 README 报错指南处理。

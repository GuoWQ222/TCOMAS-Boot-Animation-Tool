# LG600 适配与验证

当前程序支持 LG600、LG700。本文保留 LG600 的适配依据；LG700 的验证记录见同目录其他文档。

## 型号与格式

- LG600：USB VID `1A2C`、PID `1520`，480×480 JPEG 帧序列；当前适配固件 REV 0075。
- LG700：USB VID `1A2C`、PID `151C`，640×480 JPEG 帧序列；适配 REV 0067、REV 0075。
- 按型号选择命令接口、转换尺寸、缓存和备份目录；型号或设备不匹配时停止。
- 本地预览保留完整矩形画面；等比裁剪、补黑边和画质设置与写入使用相同的转换结果。

## 备份、写入与恢复

写入前完整备份开机动画和待机图，校验清单、哈希、格式和设备归属；写入后完整读回并逐字节比较。
恢复原始素材前发送 mode0，恢复完成后不自动开启离线循环。需要循环播放时，使用“修复当前离线播放”。
普通原始恢复可使用已核验的原备份；兼容转换和导入仍须先完整备份当前素材。
